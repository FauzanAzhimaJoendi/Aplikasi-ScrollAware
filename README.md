**ScrollAware** adalah aplikasi Android berbasis *behavioral design pattern* yang dirancang untuk membantu pengguna mengatasi kecanduan konten video pendek (*short-video*) seperti TikTok, Instagram Reels, dan YouTube Shorts. 


---

## 🚀 Fitur Utama

- **🔍 Real-Time Background Tracking**: Melacak durasi dan frekuensi (*launch count*) penggunaan aplikasi target secara akurat di latar belakang menggunakan Android `AccessibilityService`.
- **⚡ Gradual Behavioral Friction (Soft-Limit)**: Peringatan visual halus (seperti jeda transisi video atau efek konversi warna layar monokrom) untuk menyadarkan pengguna sebelum pemblokiran penuh.
- **🚫 Interactive App Blocker (Hard-Limit)**: Layar pemblokiran (*Overlay Window*) penuh saat batas alokasi waktu harian telah habis atau saat Jadwal Fokus/Tidur aktif.
- **🧠 Addiction Level Index (ALI)**: Kalkulasi skor adiksi kognitif berdasarkan rasio frekuensi buka dan durasi tanpa jeda sebagai instrumen evaluasi diri.
- **📊 Interactive Analytics Dashboard**: Visualisasi grafik konsumsi media sosial harian dan mingguan.
- **🧘 Micro-Break Mindfulness Prompt**: Sesi latihan pernapasan/rehat singkat sebelum tindakan pemblokiran.
- **🚨 Emergency Pass**: Fitur pintas darurat dengan sistem kuota ketat untuk melatih kedisiplinan mandiri.
